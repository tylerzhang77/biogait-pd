# Trained model files

The source revision audit package did not contain serialized trained-model checkpoints. The public
code and frozen protocol can regenerate fitted models when the input feature tables are available,
but this release must not claim that the exact fitted checkpoints are downloadable yet.

When the exact reported fits have been exported, place the files here or attach them to the
versioned GitHub/Zenodo release, record their software and data provenance, and add SHA-256 hashes
to the release manifest.
